## 反思
問了AI一些關於世界會變成怎樣的問題，得到的回覆大多都會是地球會有自然恢復的機制所以不論我們把這個環境傷害成怎樣好像都不會有永久傷害的感覺，這讓我在思考上有點無法跨出去，所以想要打破這樣的思維模式可能還是以我想像的跟努力找到一些證據去做佐證
